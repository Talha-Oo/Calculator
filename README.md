# Caluculator

### Build and Run
#### make:
to build the calculator

#### make run:
to run the calculator

### Usage:
#### The calculator supports:
- Basic arithmetic: +, -, *, /
- Parentheses
- Unary operations: sin, cos, exp, log
- Variable assignments, e.g. 5 = x
- Named constants: pi, e, Answer, L
#### Commands:
- **Vars:**  displays stored variables.
- **Clear:** clears stored variables.
- **Quit:**  exits the calculator.

The calculator also stores the latest result in ans.

#### When quitting
#### The calculator displays:
- Expressions entered
- Successfully evaluated expressions
- Fully evaluated expressions
